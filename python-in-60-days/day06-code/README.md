- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
Hi Mahyar
Hi Mahyar!
Day 6
Pizza: 180
```

## What it means

- A **string** is text in quotes. `+` joins two strings.
- An **f-string** (an `f` before the quotes) puts a variable inside the text: `{name}`.
- Math works inside the braces too.
