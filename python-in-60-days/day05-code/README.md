## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
9
5
14
3.5
14
20
150000.0
```

## What it means

- `+` add, `-` subtract, `*` multiply, `/` divide.
- `/` always gives a decimal: `7 / 2` is `3.5`.
- `*` is done before `+`, so `2 + 3 * 4` is `14`. Brackets go first: `(2 + 3) * 4` is `20`.

## یعنی چی؟

- ⁦`+`⁩ جمع، ⁦`-`⁩ تفریق، ⁦`*`⁩ ضرب، ⁦`/`⁩ تقسیم.
- ⁦`/`⁩ همیشه جواب اعشاری می‌ده: ⁦`7 / 2`⁩ می‌شه ⁦`3.5`⁩.
- ضرب قبل از جمع حساب می‌شه، پس ⁦`2 + 3 * 4`⁩ می‌شه ⁦`14`⁩. پرانتز اول حساب می‌شه: ⁦`(2 + 3) * 4`⁩ می‌شه ⁦`20`⁩.
