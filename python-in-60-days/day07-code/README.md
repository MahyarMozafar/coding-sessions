# Day 7: `input()`: ask the user

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

It asks you a question in the terminal: type your answer and press Enter.

## What it means

- `input()` asks the user a question and waits for an answer.
- The answer goes into a variable, here `name`.
- `input()` always gives **text**, even when you type a number.

## Exercise

Greet the user by name.
