# Day 10: 🛠 Mini project: an age calculator

- `main.py`: the code from the video

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

It asks you a question in the terminal: type your answer and press Enter.

## What it means

- It uses everything from Days 1–9: `input()`, `int()`, math and an f-string.
- The year is the Persian year (1405): born 1380 → 25.

## Your turn

Build your own version (for example: the age in months or days) and share it.
