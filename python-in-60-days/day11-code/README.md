## What it means

- `>` bigger, `<` smaller, `>=` bigger or equal, `<=` smaller or equal.
- `==` asks "equal?" and `!=` asks "not equal?".
- The answer is always `True` or `False`. One `=` puts a value in a box; two `==` compare.
