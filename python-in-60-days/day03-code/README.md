## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
Mahyar
3
```

Now change `"Mahyar"` to `"Sara"` and run it again: the output changes too.

## What it means

- A **variable** is a box with a name. `name = "Mahyar"` puts `"Mahyar"` in a box called `name`.
- `=` means "put into the box". It is not "equals" like in math.
- `print(name)` prints what is **inside** the box. The variable name has no quotes.

## یعنی چی؟

- **متغیر** یه جعبه با اسمه. ⁦`name = "Mahyar"`⁩ مقدار ⁦`"Mahyar"`⁩ رو توی جعبه‌ای به اسم ⁦`name`⁩ می‌ذاره.
- ⁦`=`⁩ یعنی «بذار توی جعبه»؛ مثل مساوی ریاضی نیست.
- ⁦`print(name)`⁩ چیزی که **داخل** جعبه‌ست رو چاپ می‌کنه. اسم متغیر گیومه نداره.
