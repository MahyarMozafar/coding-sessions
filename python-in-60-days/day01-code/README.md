# Day 1: Install Python + your first code

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

Open the file in VS Code and press the ▶ button at the top right. Or, in a terminal:

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
Hello world
```

## What it means

- `print( )` shows something on the screen.
- `"Hello world"` is text, so it goes inside quotes.

## Exercise

Print your name and your age, each on its own line.
