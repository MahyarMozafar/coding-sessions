## What it means

- `elif` means "else, if": one more condition to check.
- Python checks from the top. The first true condition wins and the rest are skipped.
- `else` at the end catches everything else.

## یعنی چی؟

- ⁦`elif`⁩ یعنی «وگرنه اگه»: یه شرط دیگه برای چک کردن.
- پایتون از بالا چک می‌کنه. اولین شرط درست برنده‌ست و بقیه رد می‌شن.
- ⁦`else`⁩ آخرش هر چیز دیگه‌ای رو می‌گیره.
