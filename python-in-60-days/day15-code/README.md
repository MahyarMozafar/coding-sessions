# Day 15: 🛠 Mini project: even or odd?

- `main.py`: the code from the video

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

It asks you questions in the terminal: type your answer and press Enter.

## What it means

- `%` gives the remainder of a division: `7 % 2` is `1`.
- A number is even when `n % 2 == 0`, otherwise odd.
- It uses what we learned: `input()`, `int()`, `if / else` and an f-string.
