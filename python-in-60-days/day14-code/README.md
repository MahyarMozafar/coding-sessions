# Day 14: `and / or / not`

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
True
True
False
False
```

## What it means

- `and`: both must be `True`.
- `or`: one `True` is enough.
- `not`: turns `True` into `False` and back.

## Exercise

A ticket price by age (half price under 12 or 65 and over).
