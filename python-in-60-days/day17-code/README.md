# Day 17: `while` and `break`

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)
- `bonus_lock.py`: 🔒 bonus: a phone lock that feels real (hidden PIN, locks for 10 seconds after 3 wrong tries)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

It asks you questions in the terminal: type your answer and press Enter.

## What it means

- `while` repeats as long as its condition is `True`.
- `n = n - 1` takes one away from `n` and puts the new number back in `n`. Without it, `n` stays 3 and the loop never ends.
- `while True` repeats forever; `break` leaves the loop at once.

## یعنی چی؟

- ⁦`while`⁩ تا وقتی شرطش ⁦`True`⁩ ـه تکرار می‌کنه.
- ⁦`n = n - 1`⁩ یکی از ⁦`n`⁩ کم می‌کنه و دوباره می‌ذارتش توی ⁦`n`⁩. بدون این خط، ⁦`n`⁩ همیشه سه می‌مونه و حلقه تموم نمی‌شه.
- ⁦`while True`⁩ همیشه تکرار می‌کنه؛ ⁦`break`⁩ همون لحظه از حلقه میاد بیرون.
