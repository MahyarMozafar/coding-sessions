# Day 17: `while`, `break`, `continue`

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

It asks you questions in the terminal: type your answer and press Enter.

## What it means

- `while` repeats as long as its condition is `True`.
- `break` leaves the loop at once.
- `continue` skips the rest of this round and goes to the next one.
